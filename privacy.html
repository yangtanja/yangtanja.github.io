Privacy Policy

YangTanJa Uploader · Effective date : October 1, 2026

1. Who uses this app

YangTanJa Uploader is a private tool used only by YangTanJa (양탄자), the operator of the YangTanJa YouTube channels to manage those channels. It is not offered to other users.

2. Data accessed

With the operator's permission (Google OAuth), the app accesses the following data of the operator's own YouTube channels through the YouTube API Services :

  • Video information (titles, descriptions, tags, thumbnails, captions, playlists, comments).
  • YouTube Analytics and Reporting data (views, watch time, impressions, click-through rate).

3. How data is used and stored

  • Data is used only to update the operator's own videos and to create a private report for the operator.
  • Access tokens and reports are stored only on the operator's own computer. Nothing is sent to any other server.
  • Data is never sold, shared or disclosed to any third party, and is not used for advertising.

4. YouTube API Services

This app uses the YouTube API Services. By using it, you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

5. Revoking access

Access can be revoked at any time on the Google security settings page. Locally stored tokens and reports can be deleted by removing the app's files.
